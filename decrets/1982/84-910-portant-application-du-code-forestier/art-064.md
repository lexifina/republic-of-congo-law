# Article 64

La décision accordant le permis est remise à l'intéressé en échange du paiement de la taxe forestière" correspondante. Si le demandeur a obtenu récemment un permis de ce type, la décision précédente lui est retirée.
La décision précise éventuellement les marques qui doivent être portées sur les produits, si le Directeur Régional le juge nécessaire.
