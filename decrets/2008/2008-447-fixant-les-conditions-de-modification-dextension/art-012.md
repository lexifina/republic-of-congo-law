# Article 12

La carte professionnelle de commerçant est invalidée dans les cas suivants :
- expiration du délai de validité ;
- falsification ,
- obtention sur la base de fausses informations ;
- usage frauduleux ;
- cession ou cessation d’activités de commerce ;
- changement intervenu en cours d’exploitation dans une ou plusieurs mentions.
