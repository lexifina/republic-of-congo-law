# Article 26

(nouveau) : L’unité forestière d’aménagement Pokola est répartie en séries d’aménagement suivantes :
- série de production : 279.190 hectares ;
- série de conservation : 4.690 hectares ;
- série de protection: 141.370 hectares ;
- série de développement communautaire : 26.950 hectares ;
- série de recherche : cette série est transversale à toutes les autres séries.
