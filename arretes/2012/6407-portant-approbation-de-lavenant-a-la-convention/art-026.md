# Article 26

(nouveau) : L’unité forestière d’aménagement Loundoungou-Toukoulaka est répartie en séries d’aménagement suivantes :
- série de production : 444.100 hectares ;
- série de conservation : 12.800 hectares ;
- série de protection : 80.500 hectares ;
- série de développement communautaire : 33.700 hectares ;
- série de recherche : cette série est transversale à toutes les autres séries.
