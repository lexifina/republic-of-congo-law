# Article 44

La série de développement communautaire comprend :
- les zones agro forestières ;
- les zones de production forestière.
Elle couvre une superficie totale de 83.700 hectares, répartie entre les villages suivants :
- Ipendja Pape
- Beye
- Seké
- Molapa
- Anikou
- Bangui Motaba
- Bonguinda
- Mbanza Molembé
- Mbéti
- Bondeko
- Bene
- Mboua
- Inriganga/Attention, Mbili
- Mossombo
- Toukoulaka/Djelo
- Mobangui
- Mobaye/lbamba
- Camp CIB Loundoungou
