# Article 74

- Dans les autres cas de responsabilité civile qui pourront se presenter dans les affaires crimine les, correctionnelles ou de police, les cours et tribunaux devant qui ces affaires seront portées, se conformeront aux dispositions du Code Civil, Livre Ill, Titre IV, Chapitre II.
