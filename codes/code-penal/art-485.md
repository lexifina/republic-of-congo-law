# Article 485

- Ii y a récidive dans tous les cas prévus par le present livre, lorsqu’iI a été rendu contre le contrevenant, dans les douze mois précédents, un premier jugement pour contravention de police commise dans le ressort du même Tribunal.
L’article 463 du present Code sera applicable a toutes les contraventions de simple police, sauf le cas oü Ia loi en dispose autrement.
