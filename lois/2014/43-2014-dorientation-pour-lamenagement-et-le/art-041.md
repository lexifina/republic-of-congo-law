# Article 41

Les choix stratégiques d’aménagement du territoire sont contenus dans les documents ci-après :
- le schéma national d’aménagement du territoire ;
- le code d’aménagement du territoire ;
- le code de l’urbanisme ;
- les schémas et plans départementaux d’aménagement du territoire ;
- les schémas sectoriels ;
- les schémas directeurs de villes et les plans d’urbanisme.
