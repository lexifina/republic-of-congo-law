# Article 182

Les crédits carbone générés dans une plantation forestière privée relevant du domaine forestier de l’Etat sont la propriété de la personne physique ou morale ayant planté ladite forêt. Lorsque le propriétaire n’est pas l’exploitant des crédits carbone, la propriété de ceux-ci est déﬁ nie dans un contrat signé entre les parties.
