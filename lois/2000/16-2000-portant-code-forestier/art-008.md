# Article 8

Les forêts du domaine privé de l’Etat sont celles qui, appartenant à l’Etat, ont fait l’objet d’un classement par décret pris en Conseil des ministres.
Elles comprennent :
• les forêts de protection ;
• les forêts de conservation naturelle ;
• les forêts de production ;
• les forêts récréatives ;
• les forêts expérimentales.
