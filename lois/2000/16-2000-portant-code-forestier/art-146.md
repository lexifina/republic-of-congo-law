# Article 146

Ceux qui auront contrefait ou falsifié les marteaux forestières ou leurs marques régulièrement déposées, procuré les marteaux, en auront fait une application ou un usage frauduleux, ceux qui auront enlevé ou tenté d’enlever, falsifié ou tenté les vraies marques, seront punis d’une amende de 200.000 à 1.000.000 FCFA et d’un emprisonnement de trois mois à deux ans, ou de l’une de ces deux peines seulement.
Si les marteaux ou les marques sont ceux de l’administration des eaux et forêts, les peines prévues par le Code pénal seront appliquées.
