# Article 94

Dans le cas de récidive, la peine sera toujours doublée. Il y a récidive lorsque dans les douze mois précédents, il a été dressé contre le délinquant ou le contrevenant un procès-verbal entraînant soit transaction, soit condamnation définitive.
Les peines seront également doublées lorsque les délits ou contraventions auront été commis la nuit.
